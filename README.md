# 🦅 Eagle-Pop Elite

**Eagle-Pop Elite** is a high-performance, mobile-optimized Bubble Shooter mini-game. Built with pure JavaScript and HTML5 Canvas, it features neon aesthetics tailored for AMOLED screens and a seamless Web3 support integration.

## 🚀 Features
- **Addictive Match-3 Gameplay**: Smooth physics and bubble-snapping logic.
- **AMOLED-Ready Design**: Deep blacks and vibrant neon colors for maximum visual impact.
- **Direct Web3 Support**: Integrated Solana tipping for direct builder-to-player connection.
- **Zero Dependencies**: Lightweight and fast, built entirely in a single file.

## 🕹️ How to Play
1. **Aim**: Touch and drag to align the pointer.
2. **Shoot**: Release to fire your bubble.
3. **Pop**: Match 3 or more bubbles of the same color to score.
4. **Support**: Click the "Support the Builder" button to help the ecosystem grow!

## 🛠️ Tech Stack
- **Language**: Vanilla JavaScript (ES6+)
- **Rendering**: HTML5 Canvas API
- **Deployment**: Vercel
